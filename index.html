Featured case study

ShadowFix

Instead of reporting one aggregate score, the project evaluates what changes inside and outside shadow regions. The best benchmark configuration uses a mask-guided U-Net; the interactive automatic workflow uses an RGB-only residual model because it does not require a ground-truth mask.

  • 540 held-out ISTD test triplets at 256×256 resolution.
  • Mask-guided model: 30.189 dB PSNR and 0.9514 SSIM.
  • +3.01 dB overall and +2.21 dB shadow-region PSNR over the RGB baseline.
  • Automatic and painted-mask guided Gradio workflows with failure-case analysis.
